# ChatUI

ChatUI is a simple user interface for interacting with your AI models from different providers. You can host it in your local network for your private AI server at home and on your localhost.

## Features

* Use this app with Ollama, OpenRouter, OpenAI and Google Gemini.
* Read aloud the LLMs responses with many different TTS engines and voices
* Convert audio files directly from the chat window
* Ask the AI to send or read emails.
* Let AI create documents
* Search the web with your SearXNG instance.

## Installation

You can get the installer from the Releases page.

## How to build

If you would like to build this app for yourself, follow these steps:

1. Clone this repo using Git.
2. Install the requirements.
3. Make sure FFMpeg is in the folder.
3. Build with PyInstaller or your desired method.

## How to use

After installing, click the icon on your Desktop. You will be prompted to allow the firewall rule the first time you run it.
Then open your browser on http://localhost:5000 or on port 5000 on your local IP adress if accessing from other devices.
