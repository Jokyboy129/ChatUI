ChatUI

ChatUI is a simple open-source AI chat interface for local and cloud models.

Supported AI Providers

  • OpenAI
  • Ollama
  • OpenRouter
  • Gemini

Features

  • FFmpeg Audio Agent for converting audio
  • TTS system to read responses aloud using multiple TTS providers
  • Email Agent for sending and reading emails
  • Document Agent for creating documents when enabled

Language Support

The app supports both German and English.

Hosting

The server runs locally and is hosted on the local network on port 5000.

User System

Each user has their own isolated workspace.
