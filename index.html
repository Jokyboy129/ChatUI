ChatUI

ChatUI is a simple open-source AI chat interface for local and cloud models.

Supported AI Providers

  • OpenAI
  • Ollama
  • OpenRouter
  • Gemini
  • Mistral

Features

  • FFmpeg Audio Agent for converting audio
  • TTS system to read responses aloud using multiple TTS providers (Piper, ElevenLabs, SAPI5)
  • Email Agent for sending and reading emails
  • Document Agent for creating documents when enabled (docx, doc, rtf, txt, md, csv)
  • Web Search via SearXNG for real-time web search capabilities

Details

Language Support: The app supports both German and English.

Hosting: The server runs locally and is hosted on the local network on port 5000.

User System: Each user has their own isolated workspace.

Knowledge Base: Users can create their own custom knowledge bases to save information. Knowledge bases are strictly personal and stored in each user's isolated local database, ensuring privacy.
